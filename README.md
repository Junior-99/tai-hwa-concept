# Hill Street Tai Hwa independent concept

Seven-page React/Vite visitor guide and personal planner. Not the official restaurant website, not commissioned or endorsed; no orders, queue tickets or reservations.

Run `npm ci`, `npm run dev`, `npm run build`. Deploy `dist` with relative assets to free GitHub Pages. Dependencies are pinned consistently across the series.

## Actual functionality

Original scroll/drag Three.js noodle-bowl study, food guide with actual images, historical photo filtering and enlargement, date-aware visit planner, explicit not-a-booking acknowledgement, persistent local search/status/notes/export workspace and optional consent-based shared creator inbox with authenticated membership-enforced access. Reduced-motion support and responsive navigation.

The date reminder flags first/third Mondays according to the Facebook notice and other Mondays as a source conflict. It never certifies opening or live availability. Historical open/closed images have archive labels and are not current announcements.
